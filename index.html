Network Management

Full MikroTik Network Control

BRISK Smart Connect gives every router owner a complete network management platform — connect routers, access points and PPPoE users from one dashboard.

Multi-Router Control

Connect unlimited MikroTik routers per account via API, VPN/WireGuard, or a generated setup script. Full API control — hotspot management, bandwidth, user sessions, restart commands.

Access Point Management

Add and monitor access points across your network. View signal strength, connected users, traffic stats and restart remotely — all from the admin dashboard.

Customer Router Control

Assign routers to customers via Ethernet, wireless bridge, P2P, or VPN. Apply packages, speed limits, auto-disconnect expired users and monitor usage.

Router Owner Network

Router owners connect their MikroTik networks to BRISK. They manage customers and earn revenue — but all WiFi packages are controlled by BRISK admin only.

Real-Time Monitoring

Live bandwidth, CPU load, uptime, active sessions and traffic — powered by Socket.IO for instant updates without page refresh.

Encrypted & Secure

AES-256 router credential encryption, JWT auth, 2FA, role-based access, connection audit logs, and failed login alerts throughout.
